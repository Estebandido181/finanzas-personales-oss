# Project origin and release scope

This is a new independent snapshot of a project previously developed privately
by Estebandido181 with AI assistance. It starts a new public history; it does not
represent a long-running public OSS project. Original third-party notices are
preserved, and original development remains private.

The maintainer reports three beta testers using the private application for
approximately two weeks as of 15 October 2026. That statement has not been
independently verified. No paying-customer, downstream-dependency, external
contribution or package-download claims are made.

The snapshot uses the stable application code. Later private infrastructure
work is outside this release. Changes for this distribution include safer
example-secret handling, public CI without a private denylist, installation
and contribution documentation, the MIT license and public-repository links.
Financial reconciliation rules and database migrations are preserved.

Historical screenshots and development-agent/session configuration were not
carried over. Synthetic fixtures and tests remain available. Publishing this
code does not establish eligibility for any sponsorship program.
