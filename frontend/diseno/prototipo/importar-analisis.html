Importar movimientos del banco

Sube el Excel que descargas de la Sucursal Virtual. Primero ves qué va a pasar; no se guarda nada hasta que lo confirmes.

Cómo conseguir el archivo

  1. Entra a la Sucursal Virtual de Bancolombia.
  2. Toca «Descargar movimientos».
  3. Elige el rango de fechas.
  4. Descarga el Excel.
  5. Vuelve aquí y elige el archivo. En el celular también sirve tocar Compartir y elegir Finanzas.

El banco entrega como máximo 120 movimientos por archivo. Conviene un rango corto, por ejemplo un mes.

Anotación del prototipo: qué dato de la API alimenta cada estado

Importar: el servidor analiza el archivo sin guardar nada. El estado sale del servidor (D44): el frontend no lo deduce. Los nombres son una propuesta para el backend. Esta hoja no es parte de la pantalla.

Estado o textoDato de la API
Estado «Analizando…»GET /api/importaciones/analisis/{id} → estado ∈ leyendo, conciliando, listo, fallido. Mientras no sea listo o fallido, el botón sigue deshabilitado.
«fila 80 de 120»filas_leidas y filas_total; si faltan, el texto dice «Analizando y comparando con tus movimientos…».
